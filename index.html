Контекст

Будова JWT

Токен — це три частини в Base64url через крапку. Безпека тримається на третій: сервер мусить перевіряти підпис. Усі чотири атаки б'ють саме сюди.

  • Header — алгоритм підпису (alg) і тип
  • Payload — твердження: sub, iss, exp
  • Signature — підпис Header і Payload ключем
eyJraWQiOi…In0.eyJpc3MiOi…In0.Nu8m1…q4Xg
Header{ "alg": "RS256", "kid": "d7b6…" }
Payload{ "iss": "portswigger", "sub": "wiener" }
SignatureRSASHA256( header · payload, key )

Обхід через неперевірений підпис

Крок 01 / 06

PortSwigger · JWT authentication bypass via unverified signature ↗
Авторизувалися як wiener. У запиті GET /my-account сесія передається як JWT у cookie session.
Передали запит у Repeater. JWT складається з трьох частин — Header.Payload.Signature; виділили другу, Payload.
У Decoder розкодували Payload з Base64, змінили sub на administrator і закодували назад.
Підставили підроблений Payload у GET /admin. Підпис не перевіряється — сервер віддав 200 OK і адмінпанель.
Сформували GET /admin/delete?username=carlos з тим самим токеном — сервер повернув 302 Found.
Користувача carlos видалено, лабораторну пройдено.

Висновки

Чому це спрацювало

Безпека JWT залежить не від стійкості алгоритму, а від правильної перевірки на сервері.

01

Ігнорування підпису

Сервер приймав токен, навіть не перевіряючи його криптографічний підпис.

02

Хибна обробка alg

Логіка підпису дозволяла перемкнути алгоритм на none й вимкнути перевірку.

03

Слабкі ключі

Короткий секрет для HS256 підбирається офлайн за секунди за словником.

04

Довіра до jwk

Ключ із заголовка jwk приймався без білого списку довірених.

Рекомендації · Remediation

Як захиститися

01

Завжди перевіряти підпис

Не допускати вимкнення перевірки підпису на сервері за жодних умов.

02

Фіксувати алгоритм

Жорстко задати допустимий alg у коді й ігнорувати його підміну клієнтом.

03

Надійні ключі

Довгі випадкові секрети для симетричних схем і надійні пари для асиметричних.

04

Білий список ключів

Заборонити jwk, jku, x5u з токена; звіряти з локальним сховищем.

Дякую за увагу.
