# ЛР № 7 — Атаки на JWT-токени

Презентація-сайт до лабораторної роботи № 7 з курсу «Безпека вебдодатків»:
обхід автентифікації на основі JSON Web Tokens (PortSwigger Web Security Academy).

Білий фон, скляна оранжева хвиля на WebGL (своя на кожному слайді), Liquid Glass,
типографіка в стилі Apple. 14 слайдів, скріншоти зі звіту. Без збірки й залежностей —
можна одразу викладати на GitHub Pages.

## Запуск локально

```bash
python -m http.server 5180
```

Відкрити http://localhost:5180

## Керування

| Дія | Як |
| --- | --- |
| Наступний крок / слайд | `→` `↓` `Space` `PageDown`, колесо миші, свайп |
| Попередній | `←` `↑` `PageUp` |
| Перший / останній слайд | `Home` / `End` |
| Збільшити скріншот | клік по скріншоту, `Esc` — закрити |
| Зміст | `M` або кнопка ≡ праворуч угорі |
| На весь екран | `F` |
| Відкрити крок 4 слайда 5 | `#5.4` в адресі |

На слайдах-розборах стрілки спершу гортають кроки з скріншотами, а в кінці переходять
на наступний слайд. Будь-який скріншот відкривається на весь екран кліком.

## Структура

- `index.html` — усі слайди; кроки кожного завдання лежать у `.steps-data` (текст + рисунок)
- `css/style.css` — токени (світла й оранжева теми), скло, типографіка, базові макети
- `css/report.css` — компоненти контенту: обкладинка, картки завдань, будова JWT, крокер, лайтбокс
- `css/fonts.css` + `fonts/` — самохостовані шрифти (Inter, Cormorant Garamond, IBM Plex Mono)
- `js/background.js` — фон: скляні стрічки-хвилі, своя хвиля на кожен слайд (`WAVES`), палітри
- `js/glass.js` — рефракція Liquid Glass (Chromium; у Safari/Firefox — матове скло)
- `js/deck.js` — навігація, крокер зі скріншотами, лайтбокс, прелоадер
- `assets/fig-01.png … fig-28.png` — скріншоти, нумерація як у звіті (Рис. 1 … 28)

## Як редагувати

- Текст кроків і підписи рисунків — у блоках `.steps-data` відповідного слайда в `index.html`
  (`data-fig` — файл рисунка, вміст `<div>` — текст кроку; підпис будується з тексту).
- Хвиля на слайді — масив `WAVES` у `js/background.js`, по одному рядку на слайд у тому ж
  порядку: кут, точка, амплітуда, закрут, ширина.
- Тема слайда — `data-theme="light"` або `"orange"` (інверсія: оранжевий фон, кремова хвиля).

## Оновлення

показувати стару версію з кешу.
