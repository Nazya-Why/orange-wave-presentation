# Білий × оранж — дизайн презентації

Статичний сайт-презентація: білий фон, скляна оранжева хвиля у WebGL (своя на кожному слайді,
перетікає між ними), Liquid Glass, типографіка в стилі Apple, 15 слайдів-заготовок.
Без збірки й залежностей — можна одразу викладати на GitHub Pages.

## Запуск локально

```bash
python -m http.server 5180
```

Відкрити http://localhost:5180

## Керування

| Дія | Як |
| --- | --- |
| Наступний / попередній слайд | `→` `↓` `Space` `PageDown` / `←` `↑` `PageUp`, колесо миші, свайп |
| Перший / останній | `Home` / `End` |
| Зміст | `M` або кнопка ≡ праворуч угорі, `Esc` — закрити |
| На весь екран | `F` |
| Відкрити 7-й слайд одразу | `#7` в адресі |

## Структура

- `index.html` — слайди (`<section class="slide">`); атрибути описані в коментарі над ними
- `css/style.css` — токени (світла й оранжева теми), скло, типографіка, макети
- `js/background.js` — фон: скляні стрічки-хвилі, хвиля для кожного слайда (`WAVES`), палітри
- `js/glass.js` — рефракція Liquid Glass (Chromium; у Safari/Firefox — матове скло)
- `js/deck.js` — навігація, поява елементів, прелоадер

## Як редагувати

- Текст — прямо в `index.html`. Заголовки з класом `split` з'являються літерами,
  слово в `<em>` стає курсивним оранжевим акцентом.
- Хвиля на слайді — масив `WAVES` у `js/background.js`, по одному рядку на слайд у тому ж порядку:
  кут, точка, амплітуда, закрут, ширина. Якщо додати слайд, допиши й рядок, інакше хвилі підуть по колу.
- Тема слайда — `data-theme="light"` або `"orange"` (інверсія: оранжевий фон, кремова хвиля).
- Зображення: покласти `<img>` усередину `.media` — воно заповнить скляну панель.
